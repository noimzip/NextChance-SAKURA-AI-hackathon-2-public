# Grass-Secretary（グラス・セクレタリー）

> 「第2回 さくらのAIハッカソン」で生まれたプロジェクトです。  
> ハッカソンは終了しましたが、現在も継続して開発を進めています。

Grass-Secretary は、**AI秘書 × スケジュール管理 × 努力可視化 × 持ち物チェック**を統合した、日常の行動を支援する Web アプリです。  
予定を管理するだけでなく、「継続」「振り返り」「忘れ物防止」までを1つの体験にまとめています。

## 現在の開発ステータス

- ハッカソン向けMVPから、継続運用を見据えたプロダクトへ改善中
- UI/UX、音声対話、共有カレンダー、解析精度を段階的に強化中
- 既存機能はローカル完結で利用可能（`localStorage` ベース）

## プロダクトの特徴

### 1. AI秘書チャット

- 自然言語から予定/タスク操作（追加・更新・完了・削除）を提案
- AI提案アクションは**確認ダイアログ後に実行**（安全設計）
- 複数スレッド管理、再送信、応答整形（表形式など）に対応
- 画像添付時はマルチモーダル対応モデルを自動選択

### 2. スケジュール/タスク管理

- `task`（期限タスク）と `schedule`（時刻付き予定）を使い分け
- 終日予定、複数日予定、タグ管理、優先度表示をサポート
- 繰り返し予定（曜日指定・回数指定・永続）を扱える
- 予定の重複判定・期限超過判定を実装

### 3. カレンダー共有と権限制御

- 共有メンバー管理（OWNER / EDITOR / VIEWER_FULL / VIEWER_FREE_BUSY）
- 公開リンク（トークン）による閲覧モード切り替え
- 権限に応じて予定詳細をマスク（`Booked` 表示）

### 4. 通知リマインド

- 分/時間/日前の複数リマインド設定
- 終日予定向けの通知基準時刻（HH:MM）設定
- ブラウザ通知を使ったローカルリマインド配信

### 5. 努力の可視化（芝グラフ）

- 日次アクティビティを蓄積し、芝グラフで可視化
- 連続日数（streak）やカテゴリ別活動を集計
- チャット・予定作成・完了・写真チェックを活動ログ化

### 6. 持ち物チェッカー（画像解析）

- 画像アップロードから持ち物候補を抽出
- 予定情報（items）と照合し、未検出・余剰を判定
- 過去履歴から持ち物候補を提案し、照合対象へ反映可能
- 履歴保存（最新20件）と結果再表示に対応

### 7. 音声体験（STT/TTS）

- 音声入力（STT）でチャット送信
- 音声合成（TTS）でアシスタント応答を再生
- 対話オーバーレイ付きの連続会話フローを提供

### 8. 使いやすさ

- 単一表示/ダッシュボード表示の2レイアウト
- モバイル下部ナビゲーション対応
- テーマ切替（ライト/ダーク/システム）
- PWA対応（manifest + service worker）

## 技術スタック

### フロントエンド

- React 19
- TypeScript
- Tailwind CSS v4
- Radix UI（shadcn/uiスタイルのコンポーネント）
- Lucide React

### AI / 外部連携

- さくらのAI Engine API（Chat / Audio / Vision）
- 複数LLM・マルチモーダルモデル選択
- STT（音声認識）/ TTS（音声合成）

### 開発基盤

- Vite+（`vp` コマンド）
- Vite PWA Plugin
- テスト: `vite-plus/test`（jsdom）
- 状態管理: Custom Hooks + `localStorage`（一部 Zustand persist）

## セットアップ

```bash
vp install
cp .env.example .env
# .env に APIキー等を設定
vp dev
```

ブラウザで起動後、必要に応じて通知権限とマイク権限を許可してください。

## 開発コマンド

| コマンド     | 用途                            |
| ------------ | ------------------------------- |
| `vp dev`     | 開発サーバー起動                |
| `vp check`   | 型チェック + lint + format 検証 |
| `vp lint`    | lint 実行                       |
| `vp fmt`     | format 実行                     |
| `vp test`    | テスト実行                      |
| `vp build`   | 本番ビルド                      |
| `vp preview` | ビルド結果の確認                |

## 環境変数

`.env.example` をコピーして設定してください。

- `VITE_SAKURA_AI_API_KEY`  
  さくらのAI Engine APIキー（`UUID:SECRET` 形式）
- `VITE_SAKURA_AI_BASE_URL`  
  APIベースURL（通常は `https://api.ai.sakura.ad.jp/v1`）

## 設計メモ（運用上の前提）

- データは基本的に `localStorage` に保存されます
- AIが提案した予定操作は即時反映せず、必ずユーザー確認後に反映します
- 共有カレンダー表示では、閲覧権限に応じて詳細情報を秘匿します

## ロードマップ（短期〜中期）

- 音声対話体験の安定化（中断制御・応答品質）
- 日程調整提案ロジックの高度化（候補スコアリング強化）
- 持ち物チェッカーの精度改善と説明性向上
- 共有/権限機能の実利用シナリオ拡張
- 長期保存・同期を見据えたデータ層の拡張
